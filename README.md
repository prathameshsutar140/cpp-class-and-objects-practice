# cpp-class-and-objects-practice
Basic C++ Object-Oriented Programming (OOP) practice programs using classes and objects for Turbo C++.

# C++ OOP Practice Programs

This repository contains basic C++ programs demonstrating core Object-Oriented Programming (OOP) concepts such as classes, objects, data encapsulation, and member functions.

---

## Included Programs

* **Student Details**: Accepts and displays student roll number and name.
* **Area Calculation**: Calculates and displays the area of a rectangle based on user input.
* **Room Dimensions & Volume**: Accepts length, breadth, and height to compute area and volume.
* **Mean Calculation**: Assigns values to two numbers and calculates their mean.
* **Detailed Room Class**: Uses private data members to calculate and display the area and volume of a room using floating-point values.

---

## Technical Information

* **Language:** C++
* **Header Files Used:** `<iostream.h>`, `<conio.h>`
* **IDE/Compiler Compatibility:** Designed for legacy compilers such as **Turbo C++** (`conio.h`, `clrscr()`, `getch()`).

---

## How to Run

1. Clone or download this repository.
2. Open any `.cpp` file in **Turbo C++** or an equivalent legacy environment.
3. Compile and Run (`Ctrl + F9` in Turbo C++).
